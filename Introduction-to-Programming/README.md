# Java 入门示例

本目录收录独立的 Java 入门练习，按主题分类。编号表示学习顺序，不对应特定教材的章节编号。

| 目录 | 内容 |
| --- | --- |
| [01-basics](./01-basics/) | 基础输入输出、员工信息、温度转换 |
| [02-selection](./02-selection/) | 条件判断、生肖、闰年、三角形、方程和十六进制转换 |
| [03-loops](./03-loops/) | 循环、输入统计、密码校验、数字去重和求和 |
| [04-math](./04-math/) | 数学与几何计算 |
| [05-random](./05-random/) | 随机数练习 |

每个 `.java` 文件都是独立示例，未使用 Java package。可在本目录下编译并运行，例如：

```text
javac 01-basics/HelloWorld.java
java -cp 01-basics HelloWorld
```
